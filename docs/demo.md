   then retain the audit's exact hashes/counts. No packaging step is needed.
2. Pair through the trusted native UI, privately. Exclude pairing input and
   operator output from any future capture. Show only harmless synthetic project

   project**; change **Phase**, then reload and reopen it to inspect saved state.
   This lane did not repeat those interactions.
3. Read the actual status text. **Cloud snapshot current** describes the current
   snapshot, not inference or source capability. **Nemotron unavailable** is
   expected with the opt-in off; jobs can remain queued without a generated

   Monitoring and export are off.** are expected for a fresh preview. A cloud
   connection failure can show **offline · writes unavailable**; do not narrate
   a successful save until the canonical state is confirmed. No bridge/destination
   produces the unavailable screens described in setup; never replace them with
