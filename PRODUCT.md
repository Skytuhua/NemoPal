# Living Playbooks

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Owner-approved React/Vite inside Electron. No additional dependencies.

## Users
One owner on Windows, managing explicitly selected projects and their managers.

## Product Purpose
Observe, understand, validate, update, check in, and remember the owner's answer. The project workspace remains useful without a chat conversation.

## Operating Context
Projects on the left, a majority-width workspace in the center, selected manager chat on the right. Narrow screens show Projects, Workspace, or Chat explicitly.

## Capabilities and Constraints
Six trusted flat panel types only. Owner edits use revision checks. Drafts survive project switching. Source reading and export require explicit desktop consent; model and source prose grant no authority. Desktop main owns auth and SSE. Browser mode without preload is unavailable unless fixture mode is intentionally enabled. Nemotron and hosted integration remain unavailable while unconfigured. Pet presentation uses a restricted bridge and original local art.

## Brand Commitments
Calm, precise project tool; neutral compact chrome and working surfaces. Pet warmth is local and restrained. No borrowed Gen assets.

## Evidence on Hand
Frozen strict schemas and explicitly synthetic golden fixtures. No live model, native interaction, hosted service, or source-read acceptance is established by fixture tests.

## Accessibility & Inclusion
Keyboard operation, visible focus, readable contrast, 44px controls, reduced motion, 375px and landscape layouts.
