# Living Playbooks

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Owner-approved React/Vite inside Electron. No additional dependencies.

## Users
Nontechnical project owners on Windows, including first-time users, managing explicitly selected projects and their managers.

## Product Purpose
Observe, understand, validate, update, check in, and remember the owner's answer. The project workspace remains useful without a chat conversation.

## Operating Context
Start with a project name and goal. Projects has a real overview and navigation. The selected desktop workspace brings recorded progress, next action, connected steps, task/evidence/notes cards, a compact check-in and the manager together without ordinary main-page scrolling. Long lists scroll within their own bounds; notes and settings open details. Narrow screens show Projects, Workspace, or Chat explicitly. Settings and connection details use progressive disclosure; Sources & privacy remains directly accessible.

## Capabilities and Constraints
Six trusted flat panel types only. Owner edits use revision checks. Drafts survive project switching. Source reading and export require explicit desktop consent; model and source prose grant no authority. Desktop main owns auth and SSE. Browser mode without preload is unavailable unless fixture mode is intentionally enabled. Nemotron and hosted integration remain unavailable while unconfigured. Pet presentation uses a restricted bridge and original local art.

## Brand Commitments
Calm, readable charcoal surfaces, white text and restrained blue actions. Green reflects recorded task progress only. The owner-supplied board is a style reference, not a page or feature specification. Preserve the approved grey pixel mouse sprite unchanged; use it sparingly. Plain language, no invented metrics, people, integrations or supported capabilities. No borrowed Gen assets.

## Evidence on Hand
Frozen strict schemas and explicitly synthetic golden fixtures. No live model, native interaction, hosted service, or source-read acceptance is established by fixture tests.

## Accessibility & Inclusion
Keyboard operation, visible focus, readable contrast, 44px controls, reduced motion, 375px and landscape layouts.
